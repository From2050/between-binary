# 成年文明之路（The Walk）整合計畫

狀態：**第四版已實作**（2026-10-13），說明見 `docs/WORLD.md` 的〈The walk〉一節。分支 `feat/world-rite`。

> 2026-10-13 第四版：路邊連綿、經過就自己亮起的石堆火太刻意，改成間距不一的紀念處。沒有留下名字的時代，用那個時代的遺物代表（火邊的骨頭、象牙與長矛、岩壁上的手、骨針與獸皮、種子、泥磚門、空的王座、戰車的輪子、船錨、廢墟裡的蠟燭）；有名字的人立墓碑，刻上名字、年代和他們說過的話。每一處都要停下來用火致敬：腳邊的小石碗點起火，墓碑上的刻字透出火光，走馬燈升起、他們的剪影從霧裡出來，然後一道光從紀念處慢慢升起、再一口氣飛上天，點亮那顆星。紀念處之間的曠野上，無名的石碑隨時代越來越多，戰後成排，最後的山坡上數不清。路的盡頭是一塊還沒有刻字的石碑：刻上你的名字、日期，和「你做的每一件事，都會成為下一代的火種，也是這個時代的豐碑。」走馬燈最後一次升起，你舉著火把的剪影和一路遇見的人一起轉；然後你的星從石碑升起，成為持火者手中的火。

> 第二版繞著附近的山丘螺旋攀升，被否決：成年禮應該是「走遠」，繞圈爬高沒有遠行的感覺。第三版改為「距離就是時間」：一條約 570 m 的長路，從營火往西南西，穿過森林、越過曠野與麥田、經過焚毀的樹林，爬上遠方的山脊。年份計數器隨腳步從三十萬年前走到今天，站與站之間有旁白講述中間的歷史。灰燼一段是考驗（變暗、走不動、火點不著）。路的盡頭前方沒有路；你的星升進共用的星空，回頭望見整條火路一路亮回家，最後沿著點亮的路飛回營火，火把插回原處繼續燃燒。

> 第一版沿湖岸走，被否決：路線沒有意義，按鈕推進像投影片，也遺失了原版 demo 的節奏。第二版依「離開 → 穿越 → 歸來」重做：路線穿過木屋後的樹林、繞上新的山丘，改回按住前進、密集的火、頭頂的大星，恢復原版的八個時代。互動統一為「用你的火」；終點喚醒共用的 45 顆星並回頭望家。

> 2026-10-10 依使用者回覆調整：只共用營火，其他（星星、手印岩石、麥田等）全部新增，不併入原有的花園與木屋；允許新增光源與聲音；可修改共用資料但不可複製；雙語；放入前現代先賢（獨立檔案）；一路點亮的燈改為石堆火焰；營火旁設立看得見的起點火把。下方原始提案中與此不同之處，以此為準。
目標：以現有 `/world/` 的湖畔家園為主體，把「成年文明之路」整合進去。保留原有的場景、素材、光照、天空、音樂與互動語彙，只新增一條可以走完的儀式路線。

## 1. 讀過原 repo 後的理解

**已經存在、而且要保留的：**

| 面向 | 現況 |
|---|---|
| 場景 | 湖畔家園：工作坊小屋 (-8,-16)、營火 (-1,-5)、菜園 (-2.4,-23)。湖在東北側（水面 -5.5 m），遠方是阿爾卑斯山脊。Blender 製作的建築，Poly Haven CC0 樹木、草、蕨與掃描岩石，PBR 地面 |
| 光 | 只有三個直接光源：月光、營火、工作坊燈。另有一個低能量光探針。**不加路燈、光暈、hover 補光** |
| 天空 | 程式產生的天幕、極光、月亮與 45 顆文明之星，全都是 `starsGroup` 的子物件，**整片天空只用一個父層旋轉** |
| 人物資料 | `src/data/civilizationStars.ts` 的 45 位計算機與資訊先驅（1837–2022，分六個時代）。首頁 StarMap 與 world 共用，**記錄不改** |
| 互動語彙 | arrive → approach → stay → choose whether to read。點物件後沿曲線走過去（約 1.9 m/s），沒有 WASD。有 Field guide 鍵盤替代、Pause motion、prefers-reduced-motion、Esc 回營地 |
| 聲音 | 只有經同意才播放的鋼琴錄音（Kevin MacLeod, CC BY 4.0），**刻意移除了合成音** |
| 品質與測試 | 有效能上限（45/30 fps、像素比、陰影更新頻率）、`tests/world.test.ts`（11 項測試通過）、`docs/WORLD.md` 詳細記錄設計決策 |

**原願景已經寫好了：** `src/content/lab/civilization-star-map.mdx` 描述了「穿過曠野的步道，路本身描繪人類進展：tools, language, writing, machines, networks, intelligence……更接近一場 rite of passage」。這次整合就是把這段願景實作出來。

## 2. 整合原則

| 從原型帶過來的 | 在原 repo 裡怎麼落地 |
|---|---|
| 站點 + 親手完成的儀式動作 + 旁白 | 沿用原本的「走近 → 停留 → 卡片」節奏。每一站是一個 viewpoint，儀式動作可以點場景物件完成，也一律提供卡片上的按鈕（鍵盤／讀屏可用） |
| 先賢之星掛在站點上方 | **改為**：星星留在天幕上（遵守天空不變式）。每站喚醒該時代的星：星變亮、變大，並在天幕上畫出連線。連線是 `starsGroup` 的子物件，跟著天空一起轉 |
| 遇見的人連成星座 | 同上，星座線屬於 `starsGroup` |
| 終點自己成為一顆星 | 在 `starsGroup` 裡新增一個點；同時出現在湖面倒影（vista 的反射已經包含天空） |
| 回頭看 | 終點的鏡頭轉回營地方向：天上是你連起的星座，遠處是營火與小屋的燈 |
| 火把 | 只有火焰本身（沿用 `fireVertex/fireFragment` 的火焰 shader 與 bloom），**不加點光源** |
| 一路點亮的燈 | **待決定**，見第 6 節。原文件明確不要 path halos |
| 合成音樂與音效 | **不帶過來**，保留鋼琴 |

## 3. 路線與站點

路線 = 原有家園步道 + 菜園之後沿湖岸往西北的一段新步道（約 31 m），全長約 70 m，全部位於近景高精度地面（±50 m）內。新路段的候選點已用 `terrainHeight` 驗證：地面高度 -0.26 ～ 0.30 m，離水面 8～16 m。

| # | 地點 | 時代 | 儀式動作 | 喚醒的星 |
|---|---|---|---|---|
| 0 | 營火 (-1,-5)（原 01 Thoughts） | 火與語言 | 從營火取一支火把（按住，或按鈕） | — |
| 1 | 工作坊門廊 (-7,-8)（原 03 Lab） | 雙手與工具 | 把手按在木牆上，留下手印 | — |
| 2 | 菜園 (-2.4,-23)（原 02 Garden） | 農業，約一萬兩千年前 | 在苗床種下種子，嫩芽長出（用現有 `plant-*.png`） | — |
| 3 | 湖岸 (-3,-33) | 文字，約西元前 3200 年 | 在立石上的石板刻下自己的名字，刻在古老刻痕下方 | 見決定 2 |
| 4 | 湖岸 (-7.5,-38) | Era I · Foundations（1800s） | 抬頭喚醒五顆星 | Babbage、Lovelace、Bell、Tesla、Marconi |
| 5 | 湖岸 (-11.5,-42.5) | Era II · Theory & Warfare（1930s–40s） | 天空與極光暗下，火把只剩餘燼；點亮一支蠟燭後，光與星才回來 | Turing、Shannon、Zuse、Lamarr、von Neumann、Bush |
| 6 | 湖岸 (-15.5,-46) | Era III–V · 語言、網路、Web 與開源 | 依時間順序把星連成一條線 | Hopper … Wales（共 25 位） |
| 7 | 湖岬 (-20,-49)，面向湖與山 | Era VI · AI 與未來 → 你 | 喚醒最後九顆星；把手按在石上，按住，你的星升起，接上星座，湖面映出倒影 | Hinton … Su，以及**你** |

原有的三個地方本身就對應文明的開端：營火是故事、工作坊是工具、菜園是耕種。走道從這裡出發，原本的資訊架構（Thoughts／Lab／Garden）不受影響，只是在家園裡多了一層意義。

站點 3～7 的座標是第一版估計，實作時會再用截圖與地形取樣微調。終點可能要再往湖邊靠，讓倒影更明顯。

## 4. 檔案層級的做法

**新增**

- `src/world/rite.ts`：站點資料（純資料）、路線、進度狀態機、各時代對應的星星 id。可測試，風格同 `journey.ts`
- `src/world/rite-props.ts`：火把（火焰 shader）、手印貼花（canvas 噴點 + 挖空）、嫩芽（現有植物貼圖）、石板（canvas 文字）、蠟燭、終點石（重用掃描岩石）、星座線與你的星（皆為 `starsGroup` 子物件）

**修改**

- `terrain.ts`：`pathSegments` 加上湖岸新路段。地面壓平與步道磨損、草叢迴避都會自動跟著生效
- `shaders.ts`：星星 shader 加 `aLit` 屬性（被喚醒的星更亮、更大），加 `uDim`（第 5 站的黑暗）。天空 shader 的極光同樣受 `uDim` 影響
- `scene.ts`：建立儀式物件；星星幾何加 `aLit`；月光陰影的 target 跟著訪客移動（目前只覆蓋 (0,-13) 周圍 ±26 m）；把 rite 傳給 exploration
- `exploration.ts`：rite 模式（開始／續走／離開），站與站之間沿用現有 `move()`，速度放慢到約 1.2 m/s；站點卡片內容；點擊儀式物件；鍵盤與按鈕替代；Esc 回營地
- `journey.ts`：新增目的地「05 The walk」（Field guide），天空卡片（04）加一個「Walk beneath them」入口
- `index.astro`、`world.css`：儀式卡片（例如「Station 3 of 8 / 3200 BCE」）、儀式動作按鈕、可選的名字欄位、進度點
- `tests/world.test.ts`：路線全程在乾地上（高於湖面 0.5 m 以上）、不穿過小屋與樹幹、所有星星 id 都存在、站點依時間排序、儀式狀態機可以重來
- `docs/WORLD.md`、`docs/archive/history.md`：新增說明與歷史紀錄

**不動**：`civilizationStars.ts` 的記錄（除非決定 2 選 c）、首頁 `StarMap.tsx`、內容集合、音樂檔、Blender 素材。

## 5. 分階段

1. **骨架（可走、可測）**：`rite.ts`、湖岸步道、站與站之間的行走、站點卡片、喚醒星星、星座連線、終點的星。不新增美術
2. **儀式物件**：火把、手印、嫩芽、石板與名字、第 5 站的黑暗與蠟燭、終點石、你的星在湖面的倒影、回頭看的鏡頭
3. **打磨**：文案與語言、手機版、減少動態與鍵盤巡覽、效能（fps 上限、下載量）、文件與測試、Cloudflare Pages 預覽部署

每一階段都在 `feat/world-rite` 上提交，開 PR 到 `master`，用 Cloudflare 預覽網址審閱。WebXR（原文件註明目前不做）與「所有人共用的星空」留到之後。

## 6. 需要決定的事

1. **語言**：網站是英文，原型是中文。選項：英文／中文／雙語切換
2. **前現代的先賢**（第 0～3 站：火、手、農業、文字）。45 位都是 1837 年之後的計算機先驅：
   - a. 不放名字，以「無名的人」呈現。45 筆資料完全不動
   - b. 另建一份只在走道上出現的名單（例如恩赫杜安娜、孔子、蘇格拉底……），不出現在首頁星圖
   - c. 加進共用的 `civilizationStars`，首頁星圖也會出現
3. **一路點亮的燈**：
   - a. 用火把點燃路邊的石堆小火（只有火焰、不打光、不加地面光暈），但仍與 WORLD.md「不要 path halos」的方向有出入
   - b. 路保持不點燈，回頭看只看到天上的星座
4. **聲音**：只保留鋼琴；或允許幾個很輕的錄音音效（例如點火、手印）
5. **入口**：只放在 Field guide 和天空卡片；或在場景裡也放一個看得見的起點（例如營火旁一支插在地上的火把）
